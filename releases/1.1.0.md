## Download

Download **Etichette_Studio_Setup_Windows_x64.exe** below. Windows 10/11, 64-bit.

## Changes

- Optional in-app updates from official GitHub releases, with signature verification.
- A small update notice with Update, Later and Don't ask again. Manual checking stays available.
- Local creation history with search and project reopening.
- Explicit millimetre units, simpler settings navigation and layout fixes for smaller windows and translated text.
- Removed the 100,000-label cap. Large sequences and page plans are calculated on demand.
- Streamed SVG and data exports, cached text outlines and parallel barcode generation.
- Automatic, resource-saving and maximum-performance modes.
- NIS publisher, copyright and export metadata.

Install this version once to enable updates on older installations. Updates are downloaded only after confirmation. Label design and printing remain available offline.

Official installers are published in this repository. Checksums and updater signatures are included. The updater signature is separate from Windows Authenticode publisher certification.
